# Wallet Journal

Локальный журнал сделок и разбор публичных кошельков Solana. Главная открывает кошелёк `8PhVUPWrcU5eE1QYX6MqEseSgycPnbdRkdBUK5Rt6cDF`.

## Запуск

Понадобится Node.js 24 или новее. В папке проекта выполните `npm start` и откройте `http://localhost:8787`. Внешних npm-зависимостей нет.

Публичный RPC отдаёт историю небольшими страницами. Для более быстрой загрузки можно добавить в локальный `.env` `SOLANA_RPC_URL` с адресом личного RPC, например Helius. Там же можно задать `WALLET_ADDRESS` для главной и `PORT` для другого порта.

Для секундных свечей добавьте в `.env` строку `DMND_API_KEY=ваш_секретный_ключ` и перезапустите `npm start`. Достаточно бесплатного ключа dmnd.dev. График запрашивает эти свечи при приближении до четырёх минут и показывает примерную капитализацию в USD по историческому курсу валюты пула. При отсутствии данных используется минутная история с указанием интервала. Ранее настроенный `COINGECKO_PRO_API_KEY` также поддерживается, если `DMND_API_KEY` отсутствует.

## Как считается анализ

- Журнал распознаёт обмены с участием Pump.fun, PumpSwap и Jupiter. История относится к транзакциям, связанным напрямую с публичным адресом. Доступны автоматическое обновление открытой главной и ручная подгрузка предыдущих операций.
- Покупки и частичные продажи по одному mint собраны в позицию. Если баланс после продажи обнуляется, следующая покупка начинает новую позицию. В карточке есть суммы, средние цены и ссылки на отдельные операции. PnL закрытой позиции требует полной истории и достоверных сумм. Долларовый PnL учитывает курс и сетевую комиссию каждой операции.
- График оценивает общую капитализацию в USD по минутным ценам GeckoTerminal и текущему общему выпуску токена из Solana. Изменения выпуска за время графика не учитываются. Суммы в SOL переведены в USD приблизительно по цене открытия часа на Coinbase Exchange. Для результата позиции вход и выход пересчитываются по своим часам.
- Покупки собственных токенов определяются, когда удалось прочитать адрес создателя из события программы. Разбор сделок по действиям других создателей и сравнение с торговым планом пока требуют отдельных данных.

## Публичный доступ

Репозиторий содержит Node.js-сервер и клиент. Для сайта по публичной ссылке разверните проект на Node.js-хостинге с командой `npm start`. Укажите `HOST=0.0.0.0`, если хостинг проксирует порт приложения, и настройте ключи через переменные окружения хостинга. GitHub Pages обслуживает статические файлы, а API журнала нужен Node.js-процесс.
